Al enviar una petición POST a la ruta http://localhost:3000/registro con los datos en formato JSON, el servidor responde confirmando que la información fue recibida correctamente. La respuesta incluye el estado, el nombre y el mensaje enviados por el usuario.

Ejemplo de respuesta:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}
